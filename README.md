This project focuses on analyzing customer satisfaction data for Singapore Airlines using a large-scale passenger dataset stored in Azure SQL Database and accessed through Jupyter Notebook with Python. 


## Project Overview


Airlines around the world are constantly striving to improve the passenger experience, enhance operational efficiency, and maximize customer satisfaction. Singapore Airlines, renowned for its world-class service, has been a leader in passenger comfort, premium services, and route innovation. This project focuses on analyzing customer satisfaction data for passengers flying with Singapore Airlines, uncovering insights about passenger preferences, travel behaviors, and service impact on ratings.

The main goal of this project is to identify key factors that influence customer satisfaction, understand patterns in service delivery across different cabin classes and routes, and provide actionable insights to help the airline optimize its services.

## Data Collection Story

The data in this project has been carefully curated to simulate realistic customer feedback and operational details of Singapore Airlines flights. While the dataset is programmatically generated for scale (over 100,000 records), it draws inspiration from real-world airline operations, survey data, and publicly available flight information.

The dataset represents passengers from multiple international destinations to and from Singapore, reflecting the diversity of routes and travel experiences. It incorporates multiple aspects of passenger experience:

### Flight details: realistic Singapore Airlines flight numbers (e.g., SQ212 from Singapore to Sydney), cabin classes, and fares reflecting actual market prices.

### Booking information: whether the flight was booked online or through a travel agent, paid seat selection, and upgrade requests.

### Passenger service interactions: meals served, seat preferences, cabin bag allowance, entertainment options, and transiting behaviors.

### Satisfaction metrics: rating scores from 1 to 5, willingness to recommend the airline, and first-time flyer flags.

### Operational data: luggage weights, passenger counts, and other metrics influencing both service quality and operational efficiency.

### The data simulates realistic scenarios based on a combination of:

### Public flight schedules and routes of Singapore Airlines.

### Typical fare ranges for different cabin classes sourced from airline pricing patterns.

### Customer survey insights reported in airline industry studies (e.g., satisfaction drivers like seat comfort, food quality, entertainment, and timely service).

### Airline operational standards, such as luggage allowances, seat assignment preferences, and onboard service protocols.

This approach ensures the dataset is as close as possible to real-world airline customer experience data, making it suitable for exploratory data analysis (EDA), visualization, and building insights in Python, Azure SQL, and Power BI.

## Project Scope

This repository contains:

### Azure SQL Database: The dataset is stored in a cloud-based SQL environment, simulating enterprise-grade airline data storage.

### Jupyter Notebook (Python): Comprehensive data cleaning, exploration, and analysis using Pandas, NumPy, and Matplotlib/Seaborn.

### Power BI Dashboard (Optional): Interactive visualizations for executive-level insights on passenger satisfaction, routes, fares, and services.
